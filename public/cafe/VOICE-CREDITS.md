# Recorded lesson prompts

The Latvian prompts were generated using Google Cloud Text-to-Speech, voice **lv-LV-Chirp3-HD-Kore**. [Google Cloud Text-to-Speech](https://cloud.google.com/text-to-speech)

The English prompts use **LJ Speech (high)**, trained by Bryce Beattie on the public-domain LJ Speech Dataset. [Voice model card](https://huggingface.co/rhasspy/piper-voices/blob/main/en/en_US/ljspeech/high/MODEL_CARD) · [Dataset credits](https://keithito.com/LJ-Speech-Dataset/)

Piper generated the English PCM recordings during development. The Android app plays all prompts locally.
